## How to Take Screenshots

1. Start backend: `cd backend && npm run dev`
2. Start frontend: `cd frontend && npm run dev`
3. Seed demo data if needed
4. Log in as appropriate user type
5. Take screenshots at 1280x800 or similar
6. Crop to remove browser chrome if desired
7. Save as PNG with descriptive filename
