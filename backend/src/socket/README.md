# WebSocket Layer

Socket.IO server with Redis adapter for real-time communication.

## Files

| File | Purpose |
|------|---------|
| `socket-server.ts` | Socket.IO server initialization and event handling |
| `socket-events.ts` | Event type definitions and handlers |
| `index.ts` | Barrel exports |

## Features

- Real-time order updates
- Notification delivery
- Admin dashboard live data
- Uses Redis adapter for multi-instance support
