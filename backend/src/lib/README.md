# Backend Libraries (`lib/`)

95 shared library files providing reusable logic across the backend.

## Key Areas

- **Cache**: Redis-based caching with TTL management
- **Errors**: `AppError` class with operational/unexpected error distinction
- **Logging**: Winston-based structured logging
- **Validation**: Zod schema utilities
- **Database helpers**: Query builders and transaction wrappers
- **Security**: Input sanitization, token management
