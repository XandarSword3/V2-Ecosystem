# Frontend Components

Reusable React components organized by feature area.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `admin/` | Admin dashboard components (tables, charts, forms) |
| `module-builder/` | Dynamic module configuration UI |

## Usage

Components in this directory are imported by page components in `src/app/`. Admin-specific components are in `admin/`, and the dynamic module builder system is in `module-builder/`.
