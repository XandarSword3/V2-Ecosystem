# Frontend Source (`src/`)

Core application source code for the Next.js frontend.

## Structure

| Directory | Purpose |
|-----------|---------|
| `app/` | Next.js App Router pages and layouts (23 route groups) |
| `components/` | Reusable React components (admin, module-builder, shared) |
| `lib/` | API client, hooks, and utility functions |
| `store/` | Zustand state stores |
| `types/` | Frontend TypeScript type definitions |
| `i18n/` | Internationalization configuration |
